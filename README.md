## 扫码连接 GitHub

设置页新增「扫码连接 GitHub」。手表通过 GitHub 官方[设备授权流程](https://docs.github.com/zh/apps/oauth-apps/building-oauth-apps/authorizing-oauth-apps)申请验证码并显示二维码：用手机扫码即打开授权页，在手机上确认后，手表自动轮询并保存令牌，全程无需在手表输入密码或令牌。

- 二维码只包含登录页地址和 8 位验证码，**不含任何令牌**；设备码和最终令牌只存在本机安全存储，不写入日志、不上传第三方。
- 扫码页的二维码占据几乎全部可用宽度；**点按二维码会进入全屏放大模式**，码块进一步加大，再点一下收起。放大后依然扫不了时，可在手机浏览器打开同屏网址并手动输入验证码。
- 默认使用 GitHub CLI 的公开 OAuth `client_id`（`178c6fc778ccc68e1d6a`），授权页会显示为「GitHub CLI」。介意的话可在设置里注册自己的 OAuth 应用并填写自定义 Client ID（需在应用设置中开启设备流）。
- 验证码约 15 分钟过期；授权被拒绝或过期后可重新生成。手动输入令牌的旧方式仍保留。
- 二维码由随包附带的 Nayuki QR Code generator（MIT）本地生成并渲染，二维码矩阵与其官方 Python 参考实现逐位一致。

如出现异常，请先确认设置里的版本号，再提供 `dev.wristgit.watch` 最新 `WristGitBoot` 阶段（F10／F11／F20／F30）或 DevEco Studio 的 `Reason`。扫码流程与手势还需在 WATCH 6 真表复验。

## 腕上操作

- **横向翻页**：正文左右滑，也可点底部圆点。首页组为首页、搜索、通知、收藏；仓库组为概览、文档、代码、发布。轻主题用深色短条，黑主题用白色短条。
- **下拉负一屏**：除收藏相关页面外，在页首向下拉；兼容模式也能点页首提示条打开。打开时跟手渐变到相反主题（主页面浅色则面板黑色，反之亦然）。从面板底部的「上滑返回」区域往上滑，或滚动列表到底后继续上滑，即可跟手退出并渐变回主页面；短拖未过阈值会回弹。系统返回键仍可退出。首页的探索、榜单、最新及周期筛选继续放在负一屏。
- **表冠和主题**：表冠滑动正文，到顶部／底部继续转动时显示回弹；键盘输入期间不接管表冠。负一屏和设置均可切换浅色或黑色，主题保存在本机。首次开启有三步教程，也可从设置重看。
- **图标与品牌**：启动图标采用原创腕表／分支符号；首页的小号 Invertocat 仅作为 GitHub 集成及项目链接标识，不作为应用标志。该标识来自 [GitHub Brand Toolkit](https://brand.github.com/foundations/logo)，商标归 GitHub, Inc.，不属于本仓库的 MIT 授权范围。

## 功能

- **发现与搜索**：探索、高星新仓榜单（7 / 30 天）、近 7 天新仓；关键词、`owner/repo` 或 GitHub 仓库链接直达。支持通过系统粘贴按钮确认打开合法链接；本应用也提供 `wristgit://repo/owner/repo` 深链和文本分享入口。能否从系统分享菜单拉起由表款和分享方决定；不会接管 `github.com`，也不会后台读取剪贴板。
- **公开仓库**：Star / Fork / Issues 与 PR 合计、语言占比、主页及 Clone 地址；Issues / PR 分页、状态筛选和讨论；README 和 Release 原生格式化阅读；分支 / 目录切换、代码换行与横读。
- **连接 GitHub**：用个人访问令牌验证登录，支持按令牌权限访问私有仓库、Star / 取消 Star、订阅 / 退订、确认后 Fork、查看 GitHub 星标和接收通知。通知可按已读状态、创建者、指派、提及和订阅筛选；支持到 Issue / PR 和对应评论、发布说明，或标记已读。批量已读在提交前留有撤销窗口，提交后不冒充可恢复。通知为应用内刷新，不是系统后台推送；华为账号和 GitHub 账号互不关联。
- **收藏与双因素**：可在手表为公开仓库创建、重命名和管理收藏分组；本地分组不等于 GitHub 云端 Star Lists。TOTP 支持 Base32 和 `otpauth://totp/...`、SHA1/SHA256/SHA512，验证码在本机生成。
- **下载与测速**：公开仓库源码 ZIP 与公开 Release 附件可通过 GitHub 下载，提供进度、系统暂停／继续、取消和重试；一次一个，成功文件保存到应用沙箱（保留最近一次完成的副本）。没有私有文件直下；导出仅在手表支持系统文件保存器时可用。官方测速使用小段公开文件；手动测速地址须为可直连且支持 Range 的公开 HTTPS 文件，仅用于测速，不会接收 GitHub 凭据，也不会被设为自动下载代理。

## 连接与隐私

- GitHub API 固定走 `https://api.github.com`。应用合并并发同请求，按账号隔离短时内存缓存；只对可安全重复的 GET 做一次短退避重试，尊重 GitHub 限流，不自动重放修改类请求。下载走匿名 GitHub 域名与经校验的官方 CDN 跳转。
- PAT 和 TOTP 种子使用系统 Asset 安全存储，不写普通偏好，不同步；设备不支持时不降级成明文。建议开启手表锁屏密码。通知通常需 classic PAT 的 `notifications` 权限；私库和写操作按需授权。请只在手表输入自己的令牌，勿通过聊天或日志发送。
- Markdown 支持标题、站内锚点、列表、格式、代码块和横滑表格。README 可原生显示公开的 GitHub 图片及相对于仓库根目录的图片，每篇最多 12 张；外站、私有与加载失败的图片以替代文字显示。不会为图片发送令牌，也不会执行 HTML 或脚本。文字代码文件最多预览 128 KiB；公开下载上限 32 MiB，续传取决于服务端和本机下载能力。
